          Questions that split the pool remove many cards at once — that's Recursive Comparative Judgment.

          ProCompNav first collects every candidate, then asks short yes/no questions that split the pool until one is left. On CoIN-Bench Val Seen it asks 2.2 questions on average (when it asks), and the user replies with 4.2 tokens per episode — versus 460.2 when an agent asks an open question about each candidate.
